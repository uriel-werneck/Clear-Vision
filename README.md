🥚 Clear-Vision

Plataforma web para classificação de ovos entre "rachado" e "não rachado"

## ✅ Funcionalidades

- Pré-processamento de imagem
- Classificação de rachaduras
- Persistência de dados em banco de dados
- Visualização de imagens

## ⚙️ Configurando Projeto

1.  **Clone o repositório:**
    ```bash
    git clone https://github.com/uriel-werneck/Clear-Vision.git
    cd Clear-Vision
    ```

2.  **Instale um ambiente virtual (Recomendado)**
    ```bash
    python -m venv .venv
    ```

3.  **Ative o ambiente virtual (Windows)**
    ```bash
    .venv\Scripts\activate
    ```

4.  **Instale as dependências**
    ```bash
    pip install -r requirements.txt
    ```

4.  **Migre o banco de dados**
    ```bash
    python manage.py migrate
    ```

# 🚀 Inicie a aplicação
```bash
python manage.py runserver
```

## 💻 Abra o navegador e digite
```
http://127.0.0.1:8000/
```
